# Accounts API

Account applications and accounts: opening at core banking, and funds holds for Payments.

## BIAN contract (`/v2`)

Next to its own `/v1`, the API offers BIAN's **CurrentAccount** service domain (semantic APIs
release 14.0.0), on the same queries, command handler and policies; EWP's own callers keep `/v1`.

| Endpoint | Policy | Purpose |
|---|---|---|
| `GET /v2/CurrentAccount/{id}/Retrieve` | as `GET /v1/accounts/{id}` (`AccountView`, own branch) | The account in BIAN's `CurrentAccountFacility`: number, BSB, owner, status, the current balance and (in `AccountDetails`) the available balance - the amount on hold is their difference. |
| `POST /v2/CurrentAccount/{id}/Deposit/Initiate` | as `POST /v1/accounts/cash-deposits` (`CashDepositRecord`: the Payments BFF's client only, own branch) | BIAN's `Deposit`: cash at the counter, recorded and credited (201; the same `Idempotency-Key` - also one used through `/v1` - returns the same deposit, 200). `CashDeposit` only; the depositing customer must own the account. |

Not offered: BIAN's `AmountBlock` - the funds holds are the payment saga's internal, machine-only
commands. Mapping, field by field: [doc/bian/README.md](../../../../doc/bian/README.md).

## Security controls

What this project does to stay secure: each control, what would go wrong without it, the threat it stops, and where to find it in the code. The platform-wide picture: [Architectural and security features §2](../../../../doc/Architectural-And-Security-Features-Demoable-EWP-V3.md#2-security-features).

| # | Security control | If it were missing | Threat prevented | Where to look |
|---|---|---|---|---|
| 1 | Strict access-token validation: issuer, audience, lifetime, signature against the IDP's keys, and only `typ: at+jwt` access tokens (RFC 9068); original claim names kept (`MapInboundClaims = false`) | A token issued for another API, an ID token or an expired token would be accepted | Token confusion and replay across APIs (OWASP API2 Broken Authentication) | `AddJwtBearer` in [Program.cs](Program.cs) |
